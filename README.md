# KOLOS TIG — маршрутні карти Олександра Колоса

Односторінковий сайт TIG-зварювання Олександра Колоса (Київ). Сторінка складена як підшивка технологічних карт
справжніх замовлень з його Instagram: марка металу й товщина → операції → річ → ціна, якщо вона названа.

Версія 2026-11-07 — цикл 3 на Velira Site Engine. Попередня версія (цикл 2) збережена тегом `pre-velira-20261107`.

## Запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Потім відкрийте http://127.0.0.1:4173. Збирання не потрібне.

## Рух

Фірмовий момент «Розгортка → бак»: на першому екрані лазер вирізає розгортку бака для системи опалення (AISI 304,
1,5 мм); під час прокрутки стінки згинаються, ставляться прихватки, ребра проварюються, кришка лягає, і схема
поступається справжньому фото бака. Поруч загоряються операції з посту. CSS 3D + GSAP 3.15/ScrollTrigger
(`assets/vendor/`). `prefers-reduced-motion` і відсутність JS показують зібраний бак і весь текст одразу.
