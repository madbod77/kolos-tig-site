# KOLOS TIG — Точність, яка з’єднує

Преміальний адаптивний сайт майстерні TIG-зварювання. Українська мова, графітова палітра, кислотний акцент, локальна типографіка й справжні матеріали майстерні.

## Запуск

Відкрийте `index.html` у браузері або запустіть у цій теці:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Потім відкрийте http://127.0.0.1:4173. Збирання й установлення залежностей не потрібні.

## Що працює

- Адаптивна навігація та мобільне меню.
- Послуги за матеріалами з відповідними фото.
- Фільтрація робіт і повноекранна галерея з клавіатурним керуванням.
- Форма підготовки запиту: перевіряє опис, копіює текст, пропонує ручне копіювання, коли буфер обміну недоступний.
- Перехід до реального профілю Instagram; відвідувач сам надсилає підготовлений текст і фото майстру.
- FAQ, видимий клавіатурний фокус, повернення фокуса з діалогів, `prefers-reduced-motion`.

## Редагування

`index.html` — тексти й секції; `styles.css` — палітра, типографіка й адаптивність; `app.js` — меню, галерея й запит; `assets/` — локальні зображення та шрифти. Джерела фото й походження hero: [ASSETS.md](ASSETS.md).

## Межі результату

Це готова локальна статична версія без публікації на домені. Серверного приймання заявок немає: запит надсилає сам відвідувач в Instagram. Телефон, точна адреса, ціни й обіцянки термінів не вигадані та не додані. Портфоліо складається з трьох публічно показаних робіт/деталей; фото першого екрана — окремий художній AI-образ, а не кейс майстерні.

Шрифти Manrope та Oswald локальні; OFL-ліцензії збережено в `assets/fonts/`. Під час завантаження сайт не звертається до сторонніх сервісів.
