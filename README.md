# KOLOS TIG — Точність, яка з’єднує

Односторінковий сайт майстерні TIG (аргонового) зварювання в Києві. Українська мова, графітова палітра з блакиттю
дуги, локальні шрифти Oswald / Manrope, лише справжні фото майстерні.

Версія 2026-11-06 зібрана на Velira Site Engine (цикл 2) і пройшла ворота якості (незалежний критик, 9 категорій ≥ 8).
Попередня версія збережена тегом `pre-velira-20261106`.

## Запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Потім відкрийте http://127.0.0.1:4173. Збирання не потрібне.

## Рух

Фірмовий момент «Шолом угору»: перший погляд — крізь темне віконце світлофільтра маски; на кінчику пальника на
справжньому фото спалахує й гасне дуга (власний WebGL-шейдер), потім «шолом піднімається» й фото проступає в кольорі.
Далі — прохід дуги по заголовках, розкриття плиток галереї, відблиск уздовж шва, «проварювання» лінії процесу.
GSAP 3.15 + ScrollTrigger лежать локально в `assets/vendor/` (ліцензія GSAP — `assets/vendor/GSAP-LICENSE.txt`).
`prefers-reduced-motion` вимикає весь рух; без JS увесь вміст видно.
